Domain Filtering Help

The Domain Filtering page allows you to control access to certain websites on the Internet by specifying their domains or key words. Before adding a domain filtering entry, you must ensure that Enable Firewall and Enable Domain Filtering have been selected on the Firewall page.

To add a domain filtering entry, click the Add New… button, and follow these instructions:

  1. Effective Time - Enter a time range in HHMM format to specify when the filtering should take effect. For example, if the range is 0803 - 1705 then filtering will be active from 08:03 to 17:05.
  2. Domain Name - Enter the domain or key word in the field. For example, www.xxyy.com.cn, or .net. Leave the domain field blank to filter all websites on the Internet.
  3. Status - Select Enabled or Disabled to enable or disable domain filtering.
  4. Modify - To modify or delete an existing entry.
  5. Click the Save button to save this entry.

To add additional entries, repeat steps 1-5.

To modify or delete an existing entry:

  1. Find the desired entry in the table.
  2. Click Modify or Delete as desired in the Modify column.

Click the Enable All button to enable all entries.

Click the Disable All button to disable all entries.

Click the Delete All button to delete all entries.

Click the Next button to go to the next page and click the Previous button to return to the previous page.
